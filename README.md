## 🕌 Core Pillars & Features

### 1. The Eternal Echo (Islamic Quiz & Learning Platform)
* **Para-by-Para Quran Quizzes**: Comprehensive assessments spanning all 30 Paras (Juz) of the Holy Quran, featuring 3 cognitive difficulty levels (*Easy*, *Medium*, *Hard*).
* **Chronological Seerah Timelines**: Sequential multiple-choice questions charting major eras, including Early Life, the Revelation, Makkah persecution, the Hijrah, and life in Madinah.
* **On-the-Fly AI Question Generation**: Powered by the [`GeminiService`](/nur-al-quran-and-seerah-daily/app/Services/GeminiService.php). If the pre-seeded question bank lacks questions matching a selected theme, difficulty, or Para, the application dynamically synthesizes fresh, high-quality MCQs using strict JSON Schema constraints.
* **Personalized Daily Insights**: Informational articles detailing Quranic history (preservation, linguistic miracles) and Seerah narratives, accompanied by interactive review questions.
* **Quran.com OAuth & Profile Sync**: Authenticating via Quran.com automatically links user profiles to synchronize reading milestones, pull reading streaks, and update the Quran Foundation API.
* **Passwordless OTP Authentication**: Fast, secure verification via a 6-digit email OTP. The login flow generates a personalized spiritual welcome greeting dynamically generated by AI based on the user's email.
* **Gamified Tracking & Community**: Real-time global leaderboards, learning streaks, accuracy stats, and bookmarking systems to build a custom study notebook.

### 2. Quranic Lens (Academic Collaborative Research Framework)
* **Verse Connection Directory**: Cross-references Quranic verses with:
  * **Hadith**: Links verses with authenticated narrations.
  * **Seerat**: Maps historical milestones in the Prophet's ﷺ life to specific revelations.
  * **Science**: Highlights correlations with modern scientific facts (biology, mathematics, cosmology).
  * **History**: Contextualizes events in world history.
  * **Scripture**: Compares biblical (Torah/Bible) parallel references.
* **Researcher Directory & Roles**: Allows qualified scholars to register via the Researchers directory. Once approved by administrators, researchers can submit detailed research commentaries.
* **Collaborative Tagging & Analyses**: Authenticated researchers can apply:
  * **Word-Level Tags**: (Root words, grammatical roles, thematic significance).
  * **Verse-Level Tags**: (Theological principles, legal rulings, prophecies).
  * **Academic Analyses**: Multi-layered theological, scientific, and linguistic essays.
* **Moderation Workflows**: A double-sync approval pipeline for administrators and senior researchers to audit pending analyses, tags, and connection links.

### 3. Android Mobile Companion App
* **Kotlin & Jetpack Compose Frontend**: Clean, responsive native Android UI utilizing Coroutines for asynchronous network tasks.
* **Auth Integration**: OTP registration and secure login/password set/change syncing.
* **Surah & Connection Viewer**: Read through all 114 Surahs and query structural connection data (Science, Seerah, Hadith, History, Scripture) on any verse dynamically.
* **Theme-Based Quizzing**: Request custom quizzes by theme and difficulty, directly updating the global database.
* **Live Leaderboards**: View global scores and rank on mobile.

## ⚙️ Installation & Setup

### 1. Web Backend Setup

#### Prerequisites
* **PHP 8.2 or higher**
* **Composer** (PHP dependency manager)
* **Node.js & NPM**
* **SQLite** (or a MySQL instance if using production migrations)

#### Step-by-Step Installation
1. **Clone the Repository:**
   ```bash
   git clone https://github.com/MuhammadSaadSiddique/nur-al-quran-and-seerah-daily.git
   cd nur-al-quran-and-seerah-daily
   ```

2. **Run the Automatic Setup Script:**
   The project contains a pre-configured automation script inside [`composer.json`](file:///d:/nur-al-quran-and-seerah-daily/composer.json) that installs dependencies, duplicates environment templates, generates encryption keys, triggers migrations, and compiles frontend assets:
   ```bash
   composer run setup
   ```

   *Manual step execution fallback:*
   ```bash
   # Install backend libraries
   composer install

   # Setup configuration file
   copy .env.example .env

   # Generate app secure keys
   php artisan key:generate

   # Create SQLite database file
   type nul > database/database.sqlite

   # Migrate schemas
   php artisan migrate --force

   # Install & compile UI files
   npm install
   npm run build
   ```

3. **Configure Environment Variables:**
   Update your API credentials inside your `.env` configuration file:
   ```env
   APP_NAME="The Eternal Echo"
   APP_URL=http://localhost:8000

   DB_CONNECTION=sqlite

   # Google Gemini API key (Mandatory for AI question and analysis generation)
   GEMINI_API_KEY="your-gemini-api-key"

   # Quran.com OAuth Credentials (For Streak & Milestone sync)
   QURAN_CLIENT_ID="your-client-id"
   QURAN_CLIENT_SECRET="your-client-secret"
   QURAN_REDIRECT_URI="http://localhost:8000/oauth/callback"
   QURAN_AUTH_URL="https://quran.com"
   QURAN_API_URL="https://api.quran.com"

   # Mail settings (For user registration/login OTP deliveries)
   MAIL_MAILER=smtp
   MAIL_HOST=smtp.mailtrap.io
   MAIL_PORT=2525
   MAIL_USERNAME=your-smtp-username
   MAIL_PASSWORD=your-smtp-password
   ```

4. **Boot the Development Ecosystem:**
   Run the unified development command to launch Vite, local PHP server, logs tailer, and background queue workers concurrently:
   ```bash
   composer run dev
   ```
   Open `http://localhost:8000` in your web browser.

### 2. Android Mobile App Setup

#### Prerequisites
* **Android Studio Koala** or newer.
* **JDK 17** configured in your project settings.
* An Android Virtual Device (AVD) or a physical Android device connected via ADB.

#### Project Configuration & Build
1. Open the [mobile-app](file:///d:/nur-al-quran-and-seerah-daily/mobile-app) folder inside Android Studio.
2. Open [`ApiClient.kt`](file:///d:/nur-al-quran-and-seerah-daily/mobile-app/app/src/main/java/com/example/eternalechomobile/data/ApiClient.kt) and configure your backend endpoint IP:
   ```kotlin
   private const val BASE_URL = "http://<YOUR_LOCAL_IP>:8000/api/v1/mobile.php"
   ```
3. Sync Gradle and build the project.
4. Run the application from Android Studio, or compile the debug APK using the CLI:
   ```bash
   # In the /mobile-app directory
   ./gradlew assembleDebug
   ```

## 🌐 Developer API Reference

For full schemas, see the complete [API Documentation](file:///d:/nur-al-quran-and-seerah-daily/docs/api.md).

### Base Headers
```http
Accept: application/json
Content-Type: application/json
```

### Authentication Modes
1. **Sanctum User Token**: Required for posting research analyses (`Authorization: Bearer <token>`). Get token via `POST /api/token`.
2. **Admin Token**: Required for bulk question uploading (`X-Admin-Token: <token>`).

### Endpoint Summary

#### 🔑 Get Token (`POST /api/token`)
* Get a Sanctum token for authenticated academic contributions.
* **Payload**: `{"email": "...", "password": "..."}`

#### 📚 Get Research (`GET /api/research`)
* Fetches paginated analyses list.
* **Filters**: `lens_type`, `chapter_number`, `verse_number`, `theme_id`, `status` (pending/approved, viewable only by moderators).

#### ✍️ Post Research (`POST /api/research`)
* Submit a new analysis commentary.
* **Payload**:
  ```json
  {
    "chapter_number": 30,
    "verse_number": 48,
    "lens_type": "science",
    "title": "Atmospheric Science & Rain Formation",
    "content": "This verse describes how clouds are spread across..."
  }
  ```

#### 📦 Bulk Upload Quizzes (`POST /api/upload-questions`)
* Upload list of generated questions. Requires `X-Admin-Token`.

## 💻 Artisan CLI Commands

* **`php artisan app:sync-themes`**
  Queries generated questions and synchronizes distinct themes to the `themes` table automatically.
* **`php artisan app:migrate-to-mysql`**
  Migrates pre-seeded database content (Surahs, verses, translations) from local SQLite to a MySQL server production instance.
* **`php artisan app:update-para-numbers`**
  Recalculates and updates Para/Juz associations for questions depending on Surah/Ayat reference formats.
* **`php artisan send:weekly-research-promo`**
  Assembles newly approved academic analyses from the last 7 days and delivers a promotional digest newsletter to all subscribers.
